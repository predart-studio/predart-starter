# Build Init Prompt

Use this as the execution handoff for Claude Code or another coding agent.

## Project
- What is being built?
- For whom?
- What outcome should the website create?

## Visual Direction Summary
- Summarize the design direction in one strong paragraph.

## Motion Summary
- Summarize the motion behavior in one strong paragraph.

## Implementation Rules
- Respect `tokens.json`
- Do not hardcode colors, radii, or type values when tokens/variables should be used
- Prefer existing starter primitives where appropriate
- Keep custom project storytelling components in `components/sections/`
- Obey `06-template-usage-rules.md`

## First Build Goal
- What should the builder implement first?
